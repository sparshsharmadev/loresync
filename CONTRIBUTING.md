# Contributing

Thanks for your interest in LoreSync. The project is in early development, and privacy-sensitive product decisions are still being shaped.

## Before you start

- Open an issue before beginning a large feature or architectural change.
- Never commit real chat exports, populated databases, credentials, or screenshots containing private conversation content.
- Use synthetic fixtures when describing parser bugs or analytics behavior.
- Keep local parsing and cloud storage behavior clearly separated in user-facing copy.

## Development setup

See the root [README](README.md) for requirements, local setup, and optional Supabase configuration. Keep changes focused and document any new import format or privacy behavior.
